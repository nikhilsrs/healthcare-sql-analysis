# 🏥 Healthcare SQL Analysis Project

## 📌 Project Overview
This project analyzes healthcare patient admission, billing, insurance, and medical condition data using **MySQL**.  
The goal is to uncover insights related to patient demographics, admission patterns, revenue trends, and medical conditions to support data-driven healthcare decisions.

---

## 🗂 Dataset
- Source: Healthcare patient records (CSV)
- Records include:
  - Patient demographics (age, gender, blood type)
  - Medical conditions
  - Admission & discharge details
  - Insurance providers
  - Billing amounts
  - Test results

---

## 🛠 Tools & Technologies
- **MySQL** – Database creation, data import, SQL analysis
- **SQL** – Joins, aggregations, filtering, grouping
- **GitHub** – Project version control

---

## 🧱 Database Design
- Imported healthcare CSV into MySQL
- Cleaned and validated data
- Used structured SQL queries to analyze:
  - Patient count
  - Admission types
  - Revenue by insurance provider
  - Medical condition trends

---

## 📊 Key SQL Analysis
- Total patients and admissions
- Emergency vs elective admissions
- Revenue by insurance provider
- Most common medical conditions
- Abnormal test result analysis


---

## 🔍 Key Insights
- Emergency admissions account for a significant portion of hospital visits
- Cancer and diabetes patients contribute higher billing amounts
- Medicare and Blue Cross generate the highest revenue
- Elderly patients show higher abnormal test results

---

## 🚀 How to Run This Project
1. Import the CSV file into MySQL
2. Run SQL scripts provided in this repository
